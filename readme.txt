Projeto de Conversão Romano-Arábico
Instruções de Compilação e Execução
Requisitos

GCC/G++ (compilador C++)
Make

Para compilar o programa principal:
make
Para executar o programa principal:
./romano
Para compilar e executar os testes:
make testa_romano
./testa_romano
Para limpar arquivos gerados na compilação:
make clean


Estrutura de Arquivos
romano.cpp: Implementação das funções de conversão
romano.hpp: Cabeçalho com declarações das funções
testa_romano.cpp: Testes unitários para as funções de conversão
makefile: Script para automatizar compilação
